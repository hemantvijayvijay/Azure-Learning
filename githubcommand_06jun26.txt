Aaj Aapne Kya-Kya Seekha? (Quick Revision)


git init: Folder ko Git repository banaya.

git config: Git ko bataya ki aapka naam aur email kya hai.

git add:  (git add .\githubcommand_06jun26.txt ) (git add )  File ko tracking list (staging area) me daala.

git branch -M main : Branch ka naam main set karne ke liye

git branch :  crurrent branch Dekhne ke liye

git commit: (git commit -m "this is my second txt file") Badlavon ko ek message ke sath lock kiya.

git remote set-url: (git remote add origin <URL> ) Apne system ko internet (GitHub) ke link se joda.

git push:  (git push -u origin main)  Apne local backup ko online server par bhej diya.


Most importent TIP - 

White/Normal: File safe hai, koi naya badlav nahi hai.

Red (U - Untracked): Nayi file bani hai, par Git ne abhi backup lena shuru nahi kiya.

Green (A - Added): Aapne git add kar diya hai. Git ne file ko tyaari wali jagah (Staging Area) me daal diya hai aur backup lene ke liye bilkul taiyar hai.

Blue (M - Modified): Purani file me kuch naya badlav kiya gaya hai.
